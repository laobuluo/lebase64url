== Description ==

一个适用于WordPress的外链接跳转将文章中的外部链接转换为base64加密的格式，支持nofollow属性和白名单设置。公众号：老蒋朋友圈


## 主要功能

* 设置WordPress文章链接文本的加密URL跳转（采用BASE64加密）
* 可以设置直接跳转
* 可以设置中间页跳转过度
* 可以设置排除的网站网址
* 可以设置NOFOLLOW或者_BLANK新窗口跳转
* 插件安装和介绍：https://www.lezaiyun.com/861.html

== Installation ==

* 1、把LeBase64URL文件夹上传到/wp-content/plugins/目录下<br />
* 2、在后台插件列表中激活LeBase64URL<br />
* 3、在左侧 设置 - LeBase64URL，菜单中设置信息。<br />
